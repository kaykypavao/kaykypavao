#### 📊 [Análise de planilha de vendas](https://github.com/kaykypavao/analise-vendas-informatica-2025)

#### 💻 [BoraVaga](https://github.com/kaykypavao/BoraVaga)

Procurar emprego não deveria exigir criar conta, preencher formulários longos e ainda ficar sem saber onde a vaga fica. A pergunta que guia o projeto é simples: "Como deixar a candidatura mais rápida e simples?"

Para responder, estou planejando um app Android em que o candidato escolhe a vaga, vê no mapa a região aproximada do trabalho e envia o currículo direto para a empresa. O foco inicial é o Rio de Janeiro, com vagas de todos os tipos, de CLT a bicos.

Veja mais sobre: https://github.com/kaykypavao/BoraVaga
